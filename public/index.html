Scrape press releases from any site into any JSON format

Drop your sample .json file here or click to browse

Each year has its own URL like /news/2013/, /news/2014/. The tool scans all years automatically.

Leave empty for auto-detection, or type your own CSS selectors. Right-click any element on the site → Inspect → copy the class name.

Example 1: Listing page
<div class="post-item">
  <a class="post-title" href="/news/article-1">Article Title</a>
  <span class="post-date">16 May 2026</span>
</div>
Set:   Item row = .post-item   Title/link = .post-title   Date = .post-date

Example 2: Detail page
<h1 class="article-heading">Press Release Title</h1>
<time class="publish-date">May 16, 2026</time>
<div class="article-body">Full content here...</div>
Set:   Title = h1.article-heading   Date = .publish-date   Content = .article-body

Example 3: Nested link inside a wrapper
<div class="news-link"><a href="/news/item">Title</a></div>
Set:   Title/link = .news-link a   (selects the <a> inside .news-link)
